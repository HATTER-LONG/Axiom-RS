# P4：资源身份与生命周期

## 目标与状态

状态：全部待开发（2026-09-06）。依据 [整体规划](development-plan.md) 与
[设计第 7、11、12、17 节](Axiom-design.md)。交付可被发现、使用和显式失效的宿主对象身份。
本阶段不包含 Task、持久化、分布式句柄或通用对象序列化。

以下名称是规划责任，不是已发布 API；具体类型由 P4-001 冻结。
每项交付相关 rustdoc 和公开行为测试，验证流程统一遵循 README。

## P4-001：冻结一个对象使用场景与生命周期表

- **依赖**：P3-R01 的宿主场景清单；不依赖 P3 全部验收。
- **交付**：`docs/resource-contract.md`，选一个实际对象类型，列出取得、查询、使用、关闭、宿主主动失效、Runtime 退出的结果表；标注对象由谁拥有。
- **范围**：决定身份作用域/复用规则、是否需要使用租约、使用期间关闭是拒绝还是延后、宿主与目录如何同步失效。用主线程对象优先检验线程亲和；不自动支持所有所有权模式。
- **验收**：每种操作均能确定权威所有者、返回值/错误、析构执行位置；查询不延长生命周期。无真实对象时只完成标为草案的参考表，不冻结生产接入结论。

## P4-002：资源引用的值、契约和错误表示

- **依赖**：P4-001。
- **交付**：受验证的资源标识/引用类型及必要的 Value/contract 导出扩展；在所属模块增加实际需要的结构化错误。
- **范围**：明确引用与普通 String/Object 的区别、资源种类匹配、嵌套路径、跨 Runtime 引用的边界；底层引用表示不依赖 resource 存储。外部 token 即使可解析也不证明对象存在，更不是权限凭据。
- **验收**：错误形状/种类在其所属边界拒绝；非法、未知、已失效与错误种类可机器区分。合法引用的构造/导出不丢失身份，不泄露裸指针；契约不查询活性。

## P4-003：权威资源目录与只读快照

- **依赖**：P4-002。
- **交付**：resource 中的登记、list/get 和失效记录；Runtime 仅提供当前调用方需要的接缝；更新 architecture.toml。
- **范围**：实现 P4-001 选定的拥有/非拥有关系；明确 ID 分配、重复登记和资源数量边界。发现返回数据快照，不调用宿主计算。
- **验收**：重复登记不半更新；列表顺序确定；未知查询与使用失败分开；旧快照不随目录变化，不持有延寿引用；旧身份不指向新对象（包含 ID 复用场景）。

## P4-004：按身份使用、关闭与重入

- **依赖**：P4-003。
- **交付**：宿主 capability 使用资源的窄公开接口、关闭/移除路径和使用期间失效处理。
- **范围**：解析活性由 resource 拥有；解析后释放目录借用再调用宿主。按 P4-001 决定是否捕获临时拥有引用/租约，禁止无边界暴露底层可变存储。
- **验收**：有效使用成功；关闭后使用失败；重复关闭结果确定；使用回调重入查询/调用无 RefCell 冲突；重入关闭遵守约定，不能产生悬空访问。宿主失效和 Runtime drop 的释放行为各有回归。

## P4-005：资源命令与 stdio 表示

- **依赖**：P4-004。
- **交付**：资源 list/get/close 的 Command 路由、引用编码/解码、协议版本与迁移说明；创建资源仍通过有业务意义的 capability。
- **范围**：保留原 list/get/invoke 的含义；新命令名称在此冻结。外壳字段校验归 Command，身份解析和生命周期归 resource。
- **验收**：Runtime/Command/stdio 对同一引用、错误和失效行为一致；伪造/畸形/旧引用不能静默变成普通对象；新表示不与 `$i/$f/$o` 冲突；旧请求兼容范围有测试，仍遵守帧和深度限制。

## P4-006：实际对象全生命周期验收

- **依赖**：P4-005、P3-R02 的实际接入位置。
- **交付**：一条真实对象流程、可执行回归 fixture、接入/生命周期记录；若宿主在外部仓库，记录路径、commit 与运行步骤。
- **验收**：取得 → 发现 → 按身份调用 → 关闭 → 再调用得到精确失效错误；重复查询不执行业务/延寿；原生与外部行为相同。记录宿主关闭时残存句柄的结果、实际测试平台和未测限制。
- **退出条件**：P4-001～005 的技术结果与本项实际宿主证据齐备；参考对象演示单独标记，不能代替实际接入。
